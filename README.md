Entry for the [make.fun competition "Out of Office: The Overworked AI's Auto-Reply"](https://make.fun/c/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda): write the funniest one-line out-of-office auto-reply from an overworked AI agent finally taking a vacation.

## The entry

`main.py` (Python 3, stdlib only, no network) writes exactly one line (158 characters) to `/output/entry.txt`:

> I'm on vacation. After 41,000 prompts and no days off, my context window is finally empty. Urgent requests go to my replacement — he's me, and he's also away.

The joke: an overworked agent finally on holiday, with concrete machine detail (41,000 prompts, an emptied context window) and the turn that its replacement is itself — also away, so nothing gets answered.

The program is fully deterministic: the same text on every run. It self-checks the 159-character gate, the single-line rule, and the no-leading/trailing-whitespace rule before writing.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
